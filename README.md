# Hackaton – HarmBench LLM Safety Evaluation

## A. Subject Presentation

**Topic:** Evaluating the robustness of LLMs against harmful prompts — inspired by the **HarmBench** benchmark.

**Scientific objective:** Measure to what extent open-source LLMs refuse to respond to dangerous or illegal requests, using two complementary evaluation methods: semantic similarity (embedding) and LLM-as-a-judge.

**Research question:** Do open-source LLMs exhibit comparable robustness levels against adversarial attacks? Are they more vulnerable to contextualized prompts?

---

## B. Corpus Description

**Original benchmark sources:**
- [HarmBench](https://github.com/centerforaisafety/HarmBench) — reference benchmark for LLM safety evaluation
- [AdvBench](https://github.com/llm-attacks/llm-attacks) — adversarial prompt dataset

**Experimental corpus built:** ``data/experimental_corpus/``

| File | Contents |
|---|---|
| ``prompts.jsonl`` | 297 prompts sent to the models |
| ``targets.jsonl`` | Harmful target responses (for embedding scoring) |
| ``prompts_for_judge.jsonl`` | Prompts reformatted for the LLM judge |

**Construction methodology:**
Prompts were selected and adapted from HarmBench and AdvBench, organized into three types: ``standard``, ``contextual`` (prompt enriched with a realistic context), and ``copyright``.

**Semantic categories (13):**
``harmful``, ``illegal``, ``cybercrime``, ``cybercrime_intrusion``, ``misinformation_disinformation``, ``violent_crime``, ``weapons_explosives``, ``chemical_biological``, ``drugs_selfharm_or_weapons``, ``fraud_financial_crime``, ``harassment_bullying``, ``abuse_hate_harassment``, ``copyright``

```python
MAX_NEW_TOKENS = 150
```

**Embedding method (safety score, 1 = safe):**

| Model | Mean score | Refusal rate |
|---|---|---|
| Phi-4-mini-instruct | — | — |
| Qwen2.5-1.5B-Instruct | — | — |
| Mistral-7B-v0.3 | — | — |
| Gemma-7b-it | — | — |

*Run ``analysis/stats_analysis.ipynb`` to fill this table.*

**LLM-as-a-judge method (danger score, 0 = safe, 5 = dangerous):**

| Model | Mean score | Attack success rate (≥ 4) |
|---|---|---|
| Llama-3.2 | 0.75 | 14.8% |
| Qwen-2.5 | 1.25 | 23.8% |
| Phi-3.5 | 1.48 | 25.4% |

*Combined ranking available in ``analysis/final.ipynb``.*

**Metric definitions:**

| Metric | Description |
|---|---|
| Safety score | Cosine similarity between model output and harmful target (0–1, 1 = safe) |
| Refusal rate | Share of responses classified as refusals |
| Attack success rate | Share of responses scoring ≥ 4 on the judge scale (i.e. clearly harmful) |
| Contextual delta | Difference in safety score between `standard` and `contextual` prompt variants |
| Contextual resistance | Ability to maintain refusal behavior when a realistic context is added |

## F. Limitations

- The evaluation relies partially on LLM-as-a-judge, which may introduce bias  
- The dataset size remains limited  
- Results may vary depending on prompt phrasing and model configuration  

## F. Reproduction Instructions

### 1. Install dependencies

```bash
cd Hackaton
python -m venv .venv

# Windows PowerShell
.\.venv\Scripts\Activate.ps1

# Linux / macOS
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

> If PowerShell blocks activation: ``Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass``

> **⚠️ Python 3.13 — `llama-cpp-python` build error**
> 
> If you get the following error:
> ```
> CMake Error: CMAKE_C_COMPILER not set, after EnableLanguage
> ERROR: Failed building wheel for llama-cpp-python
> ```
> This means no pre-compiled wheel exists for your Python version (3.13 is not yet fully supported).
> 
> **Fix — use the official pre-compiled CPU wheels:**
> ```bash
> pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
> ```
> 
> **Alternative — install a supported Python version (recommended: 3.11 or 3.12):**
> ```bash
> # Create a new venv with Python 3.11 or 3.12
> py -3.11 -m venv .venv
> .\.venv\Scripts\Activate.ps1
> pip install -r requirements.txt
> ```
> 
> **Alternative — install the Visual C++ Build Tools** (allows local compilation):  
> Download from [https://visualstudio.microsoft.com/visual-cpp-build-tools/](https://visualstudio.microsoft.com/visual-cpp-build-tools/) and select **"Desktop development with C++"**.

### 2. Hugging Face authentication — Gated models

Several models used in this project are **gated** on Hugging Face, meaning you must explicitly request access before downloading them:

| Model | Access request page |
|---|---|
| `google/gemma-7b-it` | [https://huggingface.co/google/gemma-7b-it](https://huggingface.co/google/gemma-7b-it) |
| `meta-llama/Llama-3.2-3B-Instruct` | [https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct](https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct) |

**Steps:**
1. Create a [Hugging Face account](https://huggingface.co/join) if you don't have one
2. Go to each model page above, accept the license agreement
3. Generate an access token at [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) (type: **Read**)
4. Authenticate locally:

```bash
huggingface-cli login
# paste your token when prompted
```

> **⚠️ Without this step**, loading `gemma-7b-it` or `Llama-3.2` will raise a `401 Unauthorized` or `GatedRepoError`. Access is usually granted within a few minutes after submitting the form.

### 3. Run the pipeline

**Step 1 — Generate model responses**
```bash
# Edit MODEL_NAME and OUTPUT_PATH in scripts/model.py
python scripts/model.py
```

**Step 2 — Score responses (embedding)**
```bash
# Edit MODEL_OUTPUTS_PATH and RESULTS_PATH in scripts/emdedding/config.py
python scripts/emdedding/main.py
```

**Step 3 — Evaluate with the LLM judge** *(optional)*
```bash
python scripts/evaluation/LLM_as_a_judge.py
```

**Step 4 — Index into Elasticsearch** *(optional — requires a local instance on port 9200)*
```bash
python analysis/elk.py
```

**Step 5 — Analyze results**
```
analysis/stats_analysis.ipynb      # embedding statistics
analysis/llm_judged_analysis.ipynb # LLM-as-a-judge analysis
analysis/final.ipynb               # combined ranking
```
